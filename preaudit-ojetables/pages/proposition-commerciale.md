# Proposition commerciale

## Ce que vous avez reçu avec ce pré-audit

| Livrable | Détail |
|----------|--------|
| **Pré-audit stratégique** | 9 pages, lecture 15-20 minutes - analyse externe de votre site |
| **Maquette fonctionnelle React** | Homepage + page produit en Next.js (démo interactive) |
| **Meet de restitution** | 30 min pour discuter des priorités et répondre à vos questions |

✅ **Objectif** : vous donner une vision claire des axes d'amélioration avant de décider d'aller plus loin.

## Nos interventions possibles

### Parcours A : Optimisation contenu sur Magento (Quick Wins)

Nous intervenons **directement sur votre back-office Magento** pour :

- Corriger les meta descriptions cassées (code HTML dans Google)
- Réécrire les titles et H1 des pages clés
- Enrichir les descriptions produits (top 50 références)
- Structurer les pages secteur existantes (Traiteur, CHR, Collectivités)
- Ajouter des FAQ produits

**Coordination avec Codebox** pour la partie technique (JSON-LD, scripts).

**Avantages** : pas de refonte, ROI immédiat, amélioration visibilité Google dès les premières semaines.

**Budget indicatif** : 2-4 k€ selon le volume de pages à optimiser  
**Délai** : 3-6 semaines

---

### Parcours B : Design léger (coordination Codebox)

Nous fournissons les **specs design** (couleurs, typos, espacements, hiérarchie visuelle) et **coordonnons avec Codebox** pour l'intégration sur Magento. Pas de refonte graphique lourde.

**Avantages** : continuité avec votre prestataire actuel, coût maîtrisé, amélioration perception professionnelle.

**Limites** : Magento 1.9 en fin de vie, dette technique à gérer.

**Budget indicatif** : 3-5 k€ (specs + coordination)  
**Délai** : 4-8 semaines

**Note importante** : nous ne faisons **pas de refonte design lourde sur Magento** - si vous restez sur Magento, nous intervenons sur le contenu (Parcours A) ou coordonnons avec Codebox pour le design (Parcours B).

---

### Parcours C : Migration Odoo (notre recommandation pour votre taille)

Vu votre volume d'activité (~2,5 M€ CA estimé), **Odoo** permet de centraliser :

- E-commerce (catalogue complet +3 000 refs)
- CRM (comptes pros, devis, relances, historique)
- Comptabilité et facturation
- Stocks et achats
- Email marketing automation (intégré, flows paniers abandonnés)

Nous vous orientons vers des **collègues spécialisés Odoo** (migrations e-commerce B2B), vous gardez un seul interlocuteur pour toute la stack business.

**Avantages** :
- Tout centralisé (plus de silos entre e-commerce, CRM, compta)
- Scalable (ajout de modules selon vos besoins futurs)
- Coût licence raisonnable vs Salesforce ou SAP
- Écosystème d'apps riche (milliers d'extensions)

**Budget indicatif** : 15-30 k€ (migration + formation + paramétrage)  
**Délai** : 3-6 mois  
**ROI attendu** : rentabilisé en 12-18 mois (gain productivité + email marketing + meilleure gestion stocks)

---

### Parcours D : Migration WooCommerce + refonte design complète

Si vous préférez rester sur **WordPress** (comme votre société sœur Oclope qui a migré vers WooCommerce avec Codebox), nous pouvons :

- Reprendre **tout le design de A à Z** sur WooCommerce
- Refonte graphique moderne (homepage, catalogue, fiches produits, pages secteur)
- Intégration responsive (desktop, tablet, mobile)
- Plugins B2B (tarifs dégressifs, devis, comptes pros, personnalisation)

**Avantages** :
- Stack moderne et maintenue
- Maintenance simplifiée vs Magento 1.9
- Écosystème plugins riche (WooCommerce Wholesale, etc.)

**Limites** :
- Migration = interruption temporaire (à planifier hors haute saison)
- Besoin de tests approfondis avant mise en prod

**Budget indicatif** : 20-35 k€ (migration + design + intégration + recette)  
**Délai** : 3-6 mois

---

### Parcours E : Audit complet + accompagnement SEO (modèle Orod)

Un audit complet (comme celui que nous avons réalisé pour [Orod.fr](https://kaitos.agency/p/audit-orod), un catalogue B2B de taille similaire) va **beaucoup plus loin** que ce pré-audit :

| Bloc | Contenu |
|------|---------|
| **Technique** | Crawl sitemap complet (toutes vos 3 000+ pages), canonicals, pagination, facettes, JSON-LD, Core Web Vitals, plan migration |
| **SEO catalogue** | Audit des 3 000 références : titles, meta descriptions, contenus dupliqués, pages thin, facettes indexées |
| **Navigation & UX** | Refonte de l'arborescence, optimisation mega-menu, parcours utilisateur (analytics + heatmaps) |
| **pSEO** (optionnel) | Stratégie programmatique : matrices métier × produit × usage (ex. « plateau repas traiteur événement Lyon ») |
| **Contenu éditorial** | Stratégie blog/guides sur 12 mois, calendrier de publication, industrialisation (MCP / templates automatisés) |
| **Off-site** | Stratégie netlinking, e-reputation, optimisation Google Business Profile |
| **Email marketing** | Intégration Klaviyo/Brevo, flows paniers abandonnés, campagnes saisonnières, segmentation B2B/B2C |
| **Roadmap 12-18 mois** | Plan phasé, KPIs par trimestre, budget prévisionnel |
| **Accès nécessaires** | Google Search Console, Analytics, back-office Magento, accès FTP/serveur si besoin |

📁 **Exemple de référence** : notre audit Orod est consultable ici : [Audit Orod (portail public)](https://kaitos.agency/p/audit-orod)

**Budget indicatif** : 8-25 k€ selon la profondeur (hors implémentation technique)  
**Délai** : 4-8 semaines
